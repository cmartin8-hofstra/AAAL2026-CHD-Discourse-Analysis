# Multimodal Coding Codebook

## AAAL 2026: Gill & Lennon (2022) Framework Application

This codebook provides detailed instructions for manually coding the visual elements of selected CHD Twitter/X exemplars using the multimodal fear appeals framework.

---

## Overview

**Framework Source**: Gill, P., & Lennon, R. (2022). A multimodal fear appeals analysis framework for vaccine misinformation. *Journal of Medical Internet Research, 24*(6), e36255.

**Exemplars to Code**: 150 (10 per chapter × 15 chapters)

**Location**: `data/analyzed/multimodal_coding_template.xlsx`

---

## Category 1: Composition

### Definition
Visual arrangement, layout, and design elements that create salience and guide viewer attention.

### What to Look For

| Element | Questions to Consider |
|---------|----------------------|
| **Layout** | Is the image centered, split-screen, or asymmetric? |
| **Salience** | What element draws the eye first? How? |
| **Framing** | Is the subject shown in full, cropped, or zoomed? |
| **Vectors** | Do lines, gazes, or gestures direct attention? |
| **Information structure** | Where is key information placed (center, top, left)? |

### Coding Examples

**High Composition Salience**:
> "Split-screen video call format with three interview panels. Central panel largest, drawing focus to main speaker. CHD TV branding at bottom creates institutional framing."

**Low Composition Salience**:
> "Simple screenshot of text post with minimal visual design elements."

## Category 2: Color

### Definition
Affective and emotional impact conveyed through color palette choices, contrast, and saturation.

### What to Look For

| Color Quality | Emotional Associations |
|---------------|----------------------|
| Red/Orange | Urgency, danger, warning, anger |
| Blue | Authority, trust, calm, institutional |
| Green | Health, safety, nature, growth |
| Black/Dark | Seriousness, death, formality, threat |
| White | Purity, innocence, clinical, sterile |
| Yellow | Warning, attention, optimism, caution |
| High saturation | Intensity, emotion, urgency |
| Desaturation | Seriousness, historical, documentary |

### Coding Examples

**Strong Color Affect**:
> "Red 'BREAKING' banner creates urgency. Blue institutional background (flags, podium) signals authority. High contrast between alert colors and formal setting amplifies tension."

**Minimal Color Affect**:
> "Primarily grayscale screenshot with default Twitter blue elements. No intentional color manipulation detected."

## Category 3: Represented Participants (RP)

### Definition
Who or what is depicted in the image, including their roles, attributes, and relationships.

### What to Look For

| Participant Type | Coding Notes |
|------------------|--------------|
| **Authority figures** | Doctors, scientists, politicians, journalists |
| **Victims** | Children, families, injured individuals |
| **Institutional symbols** | Flags, logos, podiums, buildings |
| **Scientific imagery** | Graphs, charts, medical equipment, documents |
| **Text overlays** | Quotes, statistics, headlines |

### Participant Roles

| Role | Description |
|------|-------------|
| **Actor** | Initiates action, speaks, gestures |
| **Goal** | Recipient of action or gaze |
| **Reactor** | Shows emotional response |
| **Phenomenon** | Object of contemplation or discussion |

### Coding Examples

**Multiple Participants**:
> "Three interview participants: (1) Host - female, professional attire, actor role; (2) Guest 1 - Dr. Pierre Kory, medical authority, primary speaker; (3) Guest 2 - supporting commentator. No children/victims shown. Bookshelf backgrounds signal intellectual authority."

**Single Participant**:
> "Rep. Thomas Massie speaking at House podium. Sole actor with institutional backdrop (American flag, chamber). Authority figure with political credibility markers."

## Category 4: Perspective/Angles

### Definition
Camera position and angles that establish viewer relationship to depicted content and power dynamics.

### Angle Classifications

| Angle | Viewer Relationship | Power Dynamic |
|-------|---------------------|---------------|
| **High angle** (looking down) | Viewer has power | Subject diminished |
| **Low angle** (looking up) | Subject has power | Subject aggrandized |
| **Eye level** | Equal relationship | Neutral/peer |
| **Oblique** | Detachment | Subject as "other" |
| **Frontal** | Engagement | Direct address |

### Distance Classifications

| Distance | Effect |
|----------|--------|
| **Close-up** | Intimacy, emotion, identification |
| **Medium shot** | Social distance, conversation |
| **Long shot** | Context, detachment, overview |

### Coding Examples

**Power-Establishing Angle**:
> "Low angle shot of speaker at podium, looking up at figure of authority. American flag prominently framed behind. Viewer positioned as audience member, subordinate to institutional power."

**Neutral/Peer Angle**:
> "Eye-level video call framing. All participants shown in equal-sized panels. Horizontal organization suggests democratic discussion among peers."

## Category 5: Textual Components

### Definition
Embedded text, typography, captions, and linguistic elements within the visual frame.

### What to Look For

| Element | Analytical Focus |
|---------|------------------|
| **Headlines/Banners** | What claim is foregrounded? |
| **Quotes** | Whose voice is centered? |
| **Statistics** | Numbers without context? |
| **Hashtags** | Community/movement markers |
| **Branding** | CHD TV, chapter logos |
| **Platform UI** | Retweet counts, timestamps |

### Typography Analysis

| Feature | Effect |
|---------|--------|
| ALL CAPS | Urgency, shouting |
| Bold | Emphasis, importance |
| Red text | Warning, danger |
| Quotation marks | Attribution, reported speech |
| Large font | Salience, hierarchy |

### Coding Examples

**Heavy Text Integration**:
> "Multiple textual layers: (1) 'BREAKING' banner in caps/red; (2) Quote attribution to @DrMakaryFDA; (3) Direct quote: 'Moms across America have spoken'; (4) CHD TV branding; (5) 'LIVE' indicator. Text constructs immediacy and authority through institutional voices."

**Minimal Text**:
> "Only platform-native UI elements (timestamp, interaction counts). No overlaid text or captions."

## Category 6: Fear Appeal Integration

### Definition
How all visual elements work together to construct threat, severity, susceptibility, or vulnerability.

### Fear Appeal Components (Witte, 1992)

| Component | Definition | Visual Markers |
|-----------|------------|----------------|
| **Threat severity** | How serious the danger is | Death imagery, statistics, medical settings |
| **Threat susceptibility** | How likely to be affected | Children, "your family," local references |
| **Response efficacy** | Proposed solution works | Authority endorsement, success stories |
| **Self-efficacy** | Viewer can take action | Clear calls to action, simple steps |

### Integration Analysis Questions

1. What threat is constructed? (vaccines, government, institutions)
2. Who is portrayed as vulnerable? (children, families, "you")
3. What emotional response is elicited? (fear, anger, distrust)
4. Is a solution/action proposed? (research, avoid, speak out)
5. How do visual and textual elements reinforce each other?

### Coding Examples

**Strong Fear Appeal**:
> "Integrated fear construction: (1) THREAT SEVERITY - Quote mentions 'millions of lives' alongside skeptical framing of mRNA safety; (2) SUSCEPTIBILITY - Discussion of children's treatment implies child vulnerability; (3) VISUAL SUPPORT - Authority figure (Dr. Kory) lending medical credibility to skeptical position; (4) TEXTUAL ANCHOR - 'enraged' in tweet text amplifies emotional urgency. Overall: Constructs mRNA vaccines as unverified threat to children, legitimized by medical authority."

**Weak/Absent Fear Appeal**:
> "Informational content about policy change without explicit threat construction. Positive framing ('common sense') rather than fear-based persuasion."

## Coding Procedure

### Step 1: Preparation
1. Open `multimodal_coding_template.xlsx`
2. Navigate to chapter sheet
3. Locate corresponding PNG in `outputs/exemplars/{chapter}/`

### Step 2: Initial Viewing
1. View image for 30 seconds without coding
2. Note immediate impressions
3. Identify dominant elements

### Step 3: Systematic Coding
1. Complete each category in order (1-6)
2. Write 2-4 sentences per category
3. Use specific visual evidence
4. Note uncertainties with [?]

### Step 4: Integration Review
1. Re-read all category notes
2. Complete Category 6 (Fear Appeal Integration)
3. Ensure internal consistency

### Step 5: Quality Check
1. Verify PNG ID matches template row
2. Check for empty cells
3. Review for analytical depth

## Inter-Rater Reliability

For multi-coder projects:

1. **Training set**: Code same 10 exemplars independently
2. **Calibration**: Discuss disagreements, refine definitions
3. **Reliability check**: Calculate Cohen's kappa (target: κ ≥ 0.70)
4. **Reconciliation**: Resolve discrepancies through discussion

## Common Coding Pitfalls

| Pitfall | Solution |
|---------|----------|
| Describing without analyzing | Always connect description to effect |
| Overinterpreting | Ground claims in visible evidence |
| Missing textual elements | Zoom in on image; use OCR if needed |
| Inconsistent depth | Maintain similar detail across categories |
| Ignoring platform context | Note Twitter UI elements when relevant |
